## 1. 한눈에
- 한 줄: 주제 방(스무 살의 나에게, 첫사랑에게…)에서 **모르는 사람들의 이야기를 읽고 공감**하고, **내 이야기도 남김**. 짧게도 장문도 OK. 내 이야기는 자동 번역돼 다른 나라 사람도 공감하고, 공감이 온 곳이 밤의 지구본에 불빛으로 켜짐
- 감동 한 줄: "모르는 사람이, 다른 나라 사람까지, 내 이야기에 공감했다"
- 비유: 유튜브 감성 영상 댓글창만 떼어 낸 곳. 장문 사연("내가 20대 때는…", "돌아와 은영아")이 주인공
- 퍼지는 방식: "내 이야기에 공감 해 줘" 링크 → 친구는 내 카드부터 보고 공감 → 자기 이야기도 남김
- 가입 없음 (사용자가 회원가입 싫어함)
- 해외 처음부터: 화면 한국어·영어·일본어·중국어(번체)
- 비슷한 것: The Unsent Project(첫사랑에게 못 보낸 문자, 영어, 공감 수 없음). 차이 = 여러 주제 방 · 공감 수 + 공감 지구본 · 자동 번역으로 국경 넘는 공감 · "공감 해 줘" 공유 · 사용자 제안 주제

## 2. 화면 흐름 (시안 8장 그대로)
1. **카톡으로 링크 받음**: "나 스무 살 때 얘기 썼는데 공감 3,201개 받음 ㅠ 너도 공감 해 줘" + 미리보기 이미지(이야기 첫 문장 · 공감 수 · 🌏 N개 나라)
2. **친구 이야기부터 읽기**: 공유 링크 = 그 이야기 카드가 화면 가득. 긴 글은 앞 3줄 + "더 보기". [🤍 공감] / [다른 이야기 보기 →]
3. **이야기 넘기기**: 릴스처럼 한 장씩. 다른 언어 이야기는 번역본 + "원문 보기" + "🇯🇵 일본어에서 번역". 메타: 나이대 · 나라(도시) · 공감 수
4. **주제 방 고르기**: 맨 위 "이번 달 주제" 배너(마감 날 공감 1위 발표). 방 목록(이야기 수). [+ 새 주제 제안하기]
5. **나도 한마디**: textarea(한 줄~장문, 상한 2,000자), 지금 나이대(선택: 10대~60대+), "익명 · 가입 없음 · 다른 나라엔 번역돼서 보여요"
6. **남긴 뒤**: 내 카드(나에겐 즉시, 남에겐 검수 후 공개 "보통 1분"), [친구에게 "공감 해 줘" 보내기], [내 카드 링크 저장(카톡 나에게)]
7. **다시 오면**: "내 이야기에 공감 +412 (총 1,087 · 🌏 5개 나라)" + **3D 밤의 지구본**에 공감 온 도시 불빛 + 도시별 숫자
8. **방 안 1위 보기**: 탭 전체 / 나이대별 / 나라별, 각 1위 이야기

## 3. 규칙
- 주제 방: 처음 6개는 운영자가 넣음, 닫히지 않음
  1. 스무 살의 나에게 2. 첫사랑에게 3. 헤어진 그 사람에게 4. 엄마·아빠에게 5. 그 시절을 버텨낸 나에게 6. 10년 뒤의 나에게
  - 방 이름·설명은 4개 언어로 직접 작성
- 새 주제: 누구나 제안, 제안에 공감 100개 → 정식 방(운영자 승인 플래그 두고 기본은 자동)
- 이번 달 주제(이벤트): 방 하나에 `featured_until` 설정. 마감 시각에 공감 1위 발표 화면. 12월 = "올해의 나에게", 12/31 23:59:59 KST 마감
- 공감: 이야기당 1인 1회(취소 가능). 내 이야기엔 공감 불가
- "오르는 중": 최근 24시간 공감 증가 수 기준, 숫자 같이 표시
- 정렬(넘기기 순서): 공유 링크로 왔으면 그 이야기 먼저 → 이후 섞기(최근 인기 + 새 이야기 일부 + 다른 언어 일부). 이미 본 건 브라우저가 기억해 덜 보이게
- 나이대별·나라별 1위: 공감 수 기준. 표본 적으면(이야기 5개 미만) "아직 적어요" 표시

## 4. 가입 없이
- 이야기 작성 시 무작위 `owner_token`(32바이트) 발급 → 브라우저 localStorage + "내 카드 링크"(`/me/{token}`)에 포함. DB 에는 해시만 저장
- 공감 중복 방지: `voter_key` = 쿠키 무작위 id + IP 를 섞은 해시. IP 원문 저장 안 함
- 작성 제한: 같은 voter_key 하루 이야기 10개·주제 제안 3개, 공감 분당 30회

## 5. 검수 (키 없을 때 기본, 키 생기면 AI 추가)
- 기본(항상): 욕설·비하 금칙어(한·영·일·중), 전화번호·이메일·주민번호·계좌 패턴 자동 가림, URL 금지
- 죽음·자해 낱말 → 공개 안 함(본인에게만) + 상담 안내 고정: 한국 109, 일본 #いのちSOS 0120-061-338, 대만 1925, 미국 988
- 신고: 서로 다른 voter 3번 → 자동 숨김
- AI 검수(키 있을 때만, `ANTHROPIC_API_KEY`): 기본 필터 통과 글을 Claude Haiku 로 한 번 더 판정 → 통과 시 공개. 키 없으면 기본 필터 통과 즉시 공개
- 상태: `pending` → `public` / `private`(본인만) / `hidden`(신고) / `removed`
- 테스트용 이야기: `is_seed=true` + 화면에 "테스트" 표시. 출시 전 한 번에 지울 수 있게 스크립트 제공. **가짜 사연을 진짜처럼 넣지 말 것**

## 9. DB (MySQL `star`)
- 기존 `mysql-local`(127.0.0.1:3306) 안에 새 DB `star`. 접속 정보는 `/home/binary/binaryworld/infra/docker-compose.yml` 의 wedding `DATABASE_URL` 계정 참고(문서·코드에 비밀번호 적지 말고 `.env.local` 에만)
- DB 생성 권한이 없으면 사용자에게 아래 한 줄 요청하고, 그동안은 개발을 막지 않게 진행:
  `docker exec -it mysql-local mysql -uroot -p -e "CREATE DATABASE star CHARACTER SET utf8mb4; GRANT ALL ON star.* TO '<계정>'@'%';"`
- utf8mb4 필수(이모지·일본어·중국어)
- 테이블(Prisma):
  - `room` (id, slug, featured_until, status, created_at) + `room_i18n` (room_id, lang, title, description)
  - `story` (id, room_id, body TEXT, lang, age_group nullable, country, city, status, empathy_count, report_count, owner_token_hash, voter_key, is_seed, created_at, published_at)
  - `empathy` (id, story_id, voter_key, country, city, created_at, UNIQUE(story_id, voter_key))
  - `story_translation` (story_id, lang, body, created_at, UNIQUE(story_id, lang))
  - `room_proposal` (id, title, lang, empathy_count, status, voter_key, created_at) + 제안 공감 테이블
  - `report` (id, story_id, voter_key, reason, created_at, UNIQUE(story_id, voter_key))

## 14. 결정 사항 (사용자)

## 15. 공간: 밤의 언덕 (홈 `/[lang]` 첫 화면. 별도 주소 없음, 아래로 내리면 기존 방 목록)
- 들어오면 내 실루엣(지금 Stargazer 캐릭터)이 언덕에 앉음. 다른 사람들도 같은 언덕에 실루엣으로 앉아 있음
- 걸어가서 자리를 고를 수 있음(탭/클릭한 곳으로 걸어감). 앉으면 하늘을 봄
- 다른 나라 사람은 실루엣 옆에 작은 국기(나라 코드는 지금 geo 그대로). 이름·채팅 없음
- 몸짓(정해진 것만): 손 흔들기 · 같이 하늘 보기(머리 들기) · 무릎 안기. 몸짓은 주변 사람에게 보임
- "지금 N명이 같은 하늘을 보고 있어요" + 나라별 작은 국기 줄
- 한 언덕 정원 **60명**(2026-11-15 150→60, 모닥불 둘레에 겹치지 않는 수). 넘치면 같은 화면의 두 번째 언덕(`hill-2`)으로 자동 배정. 언어별 언덕 아님(국경 넘는 공감이 목적)
- 첫 화면 = 언덕. 헤더에 방 목록·내 이야기·1위는 그대로. 기존 릴스식 넘기기·지구본은 그대로 둠

## 16. 하늘: 이야기가 별
- 공개 이야기 중 공감 1개 이상인 것이 하늘에 별로 뜸. 밝기 = 공감 수(로그). 방별로 하늘 구역(별자리)이 나뉘고 구역 이름이 옅게 보임
- 별을 누르면 그 이야기 카드가 열림(기존 StoryCard·EmpathyButton 재사용). 공감하면 별이 한 단계 밝아지고, 내 자리에서 빛 줄기가 그 별로 올라감(다른 사람에게도 보임 = 공감이 실시간으로 하늘에 번짐)
- 내 이야기를 남기면 내 자리 위로 새 별이 떠오름(다른 사람에게도 보임)
- 하늘에 올리는 별 수는 상한 300개(인기+최근+다른 언어 섞기, 기존 피드 규칙 재사용). 30초마다 갱신
- 별똥별: 누군가 새 이야기를 남기거나 공감이 생기면 가끔 떨어짐(연출)

## 17. 의식: 매일 밤 한 번

## 18. 기술
- **웹소켓은 같은 컨테이너·같은 포트**: `server.ts`(커스텀 서버)가 Next 를 품고, `/ws` 업그레이드 요청만 `ws` 라이브러리로 받음. 컨테이너·포트·Caddy 설정이 하나로 끝남. 나중에 터지면 이 파일만 분리해서 따로 띄울 수 있게 `lib/realtime/` 은 Next 에 의존하지 않게 작성
  - 대가: `next start` 대신 `node server.js`. App Router 에서 지원되는 방식. 빌드는 그대로 `next build`
  - 메시지: join(언덕 배정) · move(목표 좌표) · sit · gesture · star-born(새 이야기) · star-glow(공감) · daily(의식 시작). 좌표는 서버가 20Hz 로 묶어서 뿌림. IP·쿠키 원문은 안 보냄, voter_key 해시만
  - 인증 없음. 같은 voter_key 는 탭이 여러 개여도 한 명으로 셈
  - 재접속·끊김: 3초 안에 자동 재접속, 그동안 실루엣은 흐리게
- 3D: three.js 그대로. 언덕·실루엣·별은 전부 저폴리·인스턴싱. **폰에서 60fps·배터리** 우선. 3D 실패(WebGL 없음)하면 2D 하늘(지금 Sky) + "N명이 보고 있어요"로 자동 대체
- SEO: 언덕은 홈 안에 있고 그 아래 방 목록·이번 달 주제가 SSR 로 같이 내려감 → 크롤러·느린 폰이 빈 화면을 보지 않음
- 위치: 기존 geo(나라·도시) 그대로. 언덕에서는 나라 코드만 씀
- 부하: 150명 × 20Hz 묶음 = 언덕당 초당 메시지 20개(묶음), 메시지당 150×12바이트 ≈ 2KB → 언덕당 40KB/s 다운. 미니 PC 12코어·메모리 여유 5GB, 집 회선 업로드가 병목(언덕 10개 = 400KB/s). 그 이상이면 `/ws` 만 Cloudflare 로 분리
- 테스트: vitest 에 realtime 룸 배정·정원·한 사람 한 자리·몸짓 전달·별 갱신 규칙 추가. 브라우저 2개로 서로 보이는지 확인
- Dockerfile: CMD 를 `node server.js` 로. Caddy 는 `star.binaryworld.kr` 한 줄(웹소켓은 같은 reverse_proxy 가 자동 업그레이드)
